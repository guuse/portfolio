Hosting platform

The Kubernetes platform our client projects run on: AWS first, the same setup on Azure.

  • 8 Kubernetes clusters, the largest above 1,500 pods
  • Deploys through git with Argo CD: acceptance, then production
  • Infrastructure changes only through a gated Pulumi pipeline
  • Logs from every pod in Loki, encrypted at rest

Kubernetes, Argo CD, Pulumi, Terraform, GitHub Actions, Loki, AWS, Azure
