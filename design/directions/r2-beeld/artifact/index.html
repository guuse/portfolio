What I’ve learned

Teaching beats fixing
If I fix something myself, it’s fixed once. If I teach someone how, through a review, mentoring or a knowledge session, the team handles it next time without me.
Standardise first
One platform for every client means one way to deploy, upgrade and debug. A custom setup per project turns every upgrade and every incident into a one-off.
Everything as code
Jenkins, the infrastructure and the deployments all live in git, so every change is reviewable, repeatable and easy to trace.

From the IPv6 move

After we moved the clusters to IPv6-only, apps started hanging when they connected to a database. The database had a dual-stack address, so the apps resolved both an IPv4 and an IPv6 address, and the IPv6 connections hung because the security group only allowed IPv4. Allowing IPv6 there fixed it. The bigger lesson: IPv6-only egress only works with DNS64 and NAT64, so everything around the clusters needs testing too.
