What I’ve learned

Teaching beats fixing
Fixing it myself is quick. Showing someone how to fix it scales.
Standardise first
One platform for every client beats a custom setup per project, for the client and for whoever is on call.
Everything as code
If it isn’t in git, it doesn’t exist: infrastructure as code, Jenkins as code, GitOps.

From the IPv6 move

A database got a dual-stack address, so the apps resolved both an IPv4 and an IPv6 address. The IPv6 connections hung, because the security group only allowed IPv4. On top of that, IPv6-only egress only works with DNS64 and NAT64, so everything around it needs testing too.
