Beeld voorop

Image first. Vivid photo slots laid out like a contact sheet, an index you can scan, and a thin layer of dev detail in the metadata: mono for meta only, never for reading text.

Colour

Three options, tokens only. Each project keeps its own tone, re-derived per option, plus a deeper project ink for its caption dot, hover colour and label chip. All ratios below are measured live in the browser from the computed tokens (WCAG 2.x). Targets: body ink ≥ 7, muted ≥ 4.5, accent-as-text ≥ 4.5, subtle labels, lines and focus ≥ 3. Photo labels sit on a paper chip, so they read on any tone.

Kobalt

Default. Crisp cool white, near-black ink, an ultramarine accent.

Type

Instrument Serif for the big moments, Schibsted Grotesk for everything you read, and Geist Mono for metadata only: kicker, figure captions, frame numbers, code chips, the index numbers, the status line and the config snippet. Koppen (data-type): Serif (a) is Instrument Serif 400, big and tight; Sans (b) is Schibsted Grotesk 600 at 0.8× with −0.045em tracking. The one <em> per headline stays italic Instrument Serif, styled per colour option.
