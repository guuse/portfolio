Beeld voorop

Image first. Big photography carries the page and the text supports it. Two typefaces, one neutral ramp, one quiet accent, and a calm tone per photo.

Colour

Options only swap tokens. The ratios below are measured live in the browser from the computed token values (WCAG 2.x relative luminance). Targets: body ink ≥ 7, muted ≥ 4.5, subtle and UI lines ≥ 3.

Wit default, gallery white

Donker dark gallery, images pop

Photo tones

Each project also has its own ink (its tone, deepened per option) for the caption dot, hover colour and the image-label chip. One muted colour per image, the same in both options, because a real photo doesn’t change with the background. Each placeholder gets a soft light fall-off and a faint grain so it reads as a photo slot, not a grey box. Label ink on each tone is measured too.

Type

Instrument Serif for big moments only: the intro headline, section titles, project titles, numbers and the email address. It’s condensed and elegant, so a large headline sits calmly next to a portrait like a magazine cover line. Schibsted Grotesk for everything else: a newspaper-born sans with sturdy, slightly quirky shapes that keeps captions and body text clear without feeling like a default UI font.

Koppen (data-type, tokens only): Serif (a) sets headings in Instrument Serif 400, big and tight; Sans (b) sets them in Schibsted Grotesk 600 at 0.8× the scale with tighter tracking (−0.045em). In both, the one <em> phrase per headline stays an italic Instrument Serif in the accent, with a hand-drawn line that draws itself in once (instant under reduced motion).

Space & images

The shared 4px scale. Sections are separated by --space-section; inside the project grid items stagger by --space-3xl and --space-4xl. Image ratios: portrait 4:5, featured full-bleed (16:9 on tablet, viewport-capped on desktop), grid slots repeat wide 3:2, tall 4:5, square 1:1, 4:3. A trailing single item spans the full width at 21:9.
