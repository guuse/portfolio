MTG suite

Four tools for Magic: The Gathering, all deployed on my homelab.

Personal · 2026 · one tool is open source

Commander is the format I play most with friends. When we can’t meet up we play on Rules of 99, I keep my decks in Tutor, look up cards with Scryfall, in plain words, and brew with claude-mtg-skills.

Rules of 99

Commander in the browser for two to four players. The open-source Forge engine runs headless on the server and handles the full rules, including commander tax, commander damage and colour identity.

A WebSocket gateway sends each player only what they’re allowed to see, so the other players’ hands never leave the server. Rooms use a six-character code and survive a dropped connection, finished games can be replayed, and on a phone the table shows one board at a time.

Forge is vendored at a pinned commit, so I decide when the engine changes but have to bring in upstream fixes myself. The card data tracks upstream nightly.

Java, React, TypeScript, WebSockets and SQLite.

Tutor

A deck library and builder, with an MCP server so Claude can search the whole card pool. Card data sits in SQLite with full-text search and exact colour-identity and legality filters, and each deck shows its mana curve, colour sources, categories and an estimate of its power bracket.

Node, SQLite with FTS5, and MCP.

Scryfall, in plain words

Scryfall is the card search most players use, but its query syntax takes practice. Here you describe the cards you want. The Claude Agent SDK writes a query, tests it against Scryfall before showing it, and offers a stricter and a broader reading, each with a breakdown of what every part of the query means.

The Claude Agent SDK, Node and server-sent events.

claude-mtg-skills

Seven Claude Code skills that build, upgrade, rate and explain real decks, grounded in proven decklists and live prices. They install as a Claude Code plugin marketplace, and its helper scripts are tested to 95%+ coverage in CI.

Open source under the MIT licence: github.com/guuse/claude-mtg-skills
