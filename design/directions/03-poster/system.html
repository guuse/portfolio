AfficheThe poster system

Dutch graphic design by way of Rotterdam: the type is the image, numbers become shapes, and the 12-column grid is there so it can be broken on purpose. Flat colour, hard edges, no shadows. One variable display face does all the shouting; a book face does the explaining.

01

Principles

  1. 1The number is the picture.

    16 GB, 0 clogs, 33,000 cards. If a fact has a number, set the number huge and let a small caption explain it. No icons, no illustrations standing in for facts.

  2. 2Width is the voice.

    Anybody runs from 50% to 150% wide. Ultra-condensed for weight and density, ultra-expanded for a shout across the page. Size and weight are secondary; width is the expressive axis.

  3. 3Grid first, then break it.

    Every block snaps to 12 columns. Then one thing per section ignores it: bleeds off the edge, overlaps, or turns 90°. Never two things breaking at once.

  4. 4Flat print.

    Fields of solid colour with hard edges. Radius 0, shadow none, gradients never (a hard hatch is a pattern, not a gradient). Depth comes from overlap and scale.

  5. 5Shout in display, explain in serif.

    Display type never carries a paragraph. Long copy is Newsreader at a readable measure. Day-job titles stay small: facts in mono, not headlines.

Beyond step 9, type is fitted: the parent is a size container and the line gets font-size: calc(100cqi / var(--fit)), where --fit is the line’s measured advance in em at its width setting. No JS needed; a 1 KB script refits only if the webfont fails.

Pairing rules

  • Display line-height 0.76–0.92, tracking 0 to −0.03em. Caps labels in mono, +0.06 to +0.14em.
  • In one headline, contrast width, not family: one line at 50%, the next at 150%.
  • Body copy is Newsreader at 68ch max. Never set more than two lines of display type as running text.
  • Numerals in data: tabular-nums slashed-zero. Big numerals are always Anybody, condensed or expanded, never normal width for the hero numbers.
  • Roles and job titles are facts: mono caps at step −1. They never become the headline.

08

Imagery & icons

  • Type and shapes first. The laptop is two black bars and a square LED. The rack is three filled rectangles in a frame. Drawn in inline SVG, flat currentColor, square corners.
  • No icon set. The only glyphs are typographic: → ◀ └ ! and a filled square as bullet and live dot.
  • Photos are real or absent. Placeholders say what to shoot: the laptop behind the TV, the Zigbee stick on its cable, the wall panel. In production, photos run full-colour inside a 3px frame, cropped hard, never rounded or tinted.
  • Patterns: one hatch (45°, 2px line, hard stops), only for “spare” or “empty”.
  • No hacker imagery for the security work: no padlocks, shields or code rain. The job is described in words.
