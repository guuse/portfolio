# Security

This is a static personal site, but if you find something that looks wrong (a header, a
dependency, something in the deploy setup), I'd like to hear about it.

**Report privately** to ekkelenkampguus@gmail.com, or open a
[private security advisory](https://github.com/guuse/portfolio/security/advisories/new) on
this repo. Please don't open a public issue for it.

The same contact is published at
[`/.well-known/security.txt`](https://ekkelenkamp.dev/.well-known/security.txt) (RFC 9116).

What to expect: a reply within a week, a fix as soon as I can, and credit in the commit if
you want it. There is no bug bounty; there is a sincere thank-you.
